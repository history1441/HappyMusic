# ============================================
# 部署拓扑
#
#   ┌─────────────────────────────────────────┐
#   │           公网 / CDN                      │
#   │                                         │
#   │   前端服务器          后端服务器1    后端服务器2   │
#   │   ┌──────────┐     ┌──────────┐  ┌──────────┐ │
#   │   │ Nginx    │     │ Nginx LB │  │ Backend  │ │
#   │   │ + 前端   │────▶│ (可选)   │  │ (实例1)  │ │
#   │   │ :80      │     └────┬─────┘  └──────────┘ │
#   │   └──────────┘          │                       │
#   │                         ▼                       │
#   │               ┌──────────────┐                  │
#   │               │  共享基础设施  │                  │
#   │               │              │                  │
#   │               │ MySQL :3306  │                  │
#   │               │ Redis :6379  │                  │
#   │               │  (同一服务器)  │                  │
#   │               └──────────────┘                  │
#   └─────────────────────────────────────────┘
#
# 数据流向：
#   客户端 → 前端Nginx(:80) → 静态文件
#   客户端 → 前端Nginx(:80) → /api/* → Nginx LB → Backend
#   客户端 → 前端Nginx(:80) → /ws/* → Nginx LB → Backend (WebSocket)
#   Backend ↔ Redis (缓存 + Pub/Sub 广播)
#   Backend → MySQL (持久化)
# ============================================
